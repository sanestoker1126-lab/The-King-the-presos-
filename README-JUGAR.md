LEGEND OF PRESOS - VERSION INICIABLE WINDOWS

1. Extrae TODOS los archivos de Legend_of_Presos_JUGAR_Windows.zip a una carpeta.
2. Ejecuta JUGAR_EN_WINDOWS.cmd (doble clic).
3. El navegador abrira automaticamente http://127.0.0.1:8765/.
4. Mantén abierta la ventana de consola mientras juegas.

No necesitas instalar Node.js, Python ni Vite. Funciona sin Internet.
No abras index.html con doble clic: file:// bloquea modulos JavaScript.
Si el puerto 8765 esta ocupado, cierra la instancia anterior.
